# 📊 AICE 데이터 분석 및 머신러닝 실습

AICE 자격증 준비 및 파이썬 기반 데이터 분석 역량 강화를 위해 진행한 실습 코드 저장소입니다.

## 🛠 사용 기술 및 라이브러리
- **Language:** Python 3
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## 📌 주요 학습 및 실습 내용
1. **데이터 전처리 (Data Preprocessing)**
   - 결측치(Missing Values) 및 이상치(Outliers) 처리
   - 범주형 데이터 인코딩(One-Hot Encoding, Label Encoding) 및 피처 스케일링
2. **탐색적 데이터 분석 (EDA)**
   - 시각화 라이브러리를 활용한 변수 간 상관관계 및 분포 분석
3. **머신러닝 모델링 (Machine Learning)**
   - 분류(Classification) 및 회귀(Regression) 모델 구축
   - 모델 성능 평가 (Accuracy, F1-score, RMSE 등)
